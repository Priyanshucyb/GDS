# Garg Digital Services (GDS)

Premium responsive website for Garg Digital Services, built with React, Vite, Tailwind CSS, React Router, Framer Motion and Lucide icons.

## Run locally

Requirements: Node.js 18+ and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (normally http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Project notes

- Main pages: Home, Services, Service Details, About & Contact.
- Service content, document checklists and image URLs are managed in `src/data/content.js`.
- Business contact and location settings are in `src/data/site.js`.
- Service guidance is informational; official authorities determine eligibility, fees, approval and processing times.
- Service card photos are loaded from Unsplash and require an internet connection.
